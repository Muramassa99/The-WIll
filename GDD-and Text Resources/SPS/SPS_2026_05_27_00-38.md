  - `runtime/forge_v2/forge_v2_keybinding_state.gd`.
  - Persists to `user://settings/forge_v2_keybindings.json`.
  - Local to Forge V2 only.
  - Supports key-only, mouse-only, key+key, and key+mouse chords.
  - Uses custom local logic instead of Godot `InputMap` because Forge V2 needs scoped editor commands and arbitrary chords such as `C + F` and `C + RMB`.
- Added keybindings popup:
  - Opened from Forge V2 Settings.
  - Shows action labels on left, binding boxes on right.
  - Clicking a binding enters capture mode and shows `Press keys to bind`.
  - Escape cancels capture / closes popup layers in order.
  - Reset restores Forge V2 factory defaults.
- Added broad key capture rules:
  - Allowed: Ctrl, Shift, Tab, CapsLock, letters, top-row numbers, symbols, Insert/Delete/Home/End/PageUp/PageDown, arrows, numpad numbers.
  - Blocked: Enter, keypad Enter, Backspace, NumLock, F1-F12.
  - Fixed accidental bug where normal letter `F` was blocked by the F-key guard.
- Made Forge V2 popup/menu backgrounds opaque:
  - Settings popup.
  - Keybindings popup.
  - Forge V2 dropdown menus.
