## What Is

### Shape Authority Is Explicit

Forge V2 now has a deliberate Basic Shape branch:

```text
Primitive source
    -> primitive geometry
    -> editable brush radius

Saved Basic profile source
    -> explicit opt-in under Shape
    -> deep snapshot of saved profile data
    -> fixed authored metric geometry
    -> brush radius cannot rescale it
```

Profile editor state remains separate:

- opening a saved profile for editing does not select it for deposition;
- editing or saving in Profiles does not replace the active Shape;
- selecting a saved Basic profile under Shape creates the active deep snapshot;
- renaming, deleting, or changing the library record does not silently mutate
  the already active Shape;
- selecting a primitive clears saved-profile Shape authority and restores
  primitive radius control;
- Handle behavior and semantic tags remain separate and unchanged.

### Basic Profiles Compile Once For Runtime Use

Saving a Basic profile now compiles a versioned runtime payload from the final
resolved outline, including fillets.

The compiler records:

- record and runtime schema versions;
- the coordinate-space identifier;
- the closest-boundary clock-rule identifier;
- the final unrotated metric outline;
- the anchor-relative deposition polygon;
- the corrected anchor;
- the real exterior contact point;
- the anchor-relative contact point;
- normalized contact direction;
- anchor-to-contact distance;
- the authored rotation bias.

The mandatory anchor rule is:

```text
minimum anchor-to-final-boundary clearance = 0.0005 m
```

The compiler:

1. resolves the final outline;
2. constructs the inward `0.0005 m` valid region;
3. leaves the anchor unchanged when it remains valid;
4. otherwise moves it to the nearest valid inset position;
5. uses the real exterior outline, not the inset, for contact;
6. resolves equal-distance contact with the locked clock rule:
   - closest to local 6 o'clock first;
   - local left wins the remaining mirror tie;
7. stores anchor-relative deposition geometry.

The clearance is never silently reduced. A profile whose geometry cannot
contain the required inset is explicitly invalid and cannot be newly saved.

### Runtime Contract Validation And Migration

Compiled Basic profiles are no longer accepted merely because their version
number looks current.

Validation now checks:

- exact record/runtime versions;
- exact rule and coordinate-space identifiers;
- valid simple base and deposition polygons;
- required clearance;
- valid normalized contact direction and distance;
- deterministic contact data against the saved outline and anchor;
- exact anchor-relative polygon/contact relationships.

Library records are recompiled deterministically on load and written only when
the result changes. This repairs stale or corrupted current-schema payloads
once without repeatedly rewriting an already-current record.

Embedded active Shape snapshots inside Forge WIP/authoring state use the same
repair path. Repairable snapshots retain their saved-profile Shape authority;
only genuinely invalid/unrepairable snapshots fall back to a primitive.

### Invalid Builder Geometry Is Visible

When Basic profile deformation destroys the possible `0.0005 m` inset:

- the builder reports explicit clearance validity;
- Save is disabled;
- the Save button reads `Fix 0.5 mm Anchor Clearance`;
- its tooltip explains the invalid region;
- direct/programmatic library saves also reject the invalid Basic profile.

This preserves unrestricted creative canvas use without silently storing a
Shape that cannot satisfy its placement law.

### Volume Stroke Uses Fixed Saved Geometry

When a saved Basic profile is active:

- Volume Stroke bodies store the exact selected profile identity and snapshot;
- generated cross-sections use the compiled anchor-relative polygon;
- the mouse/surface-hit point is the saved red-dot anchor;
- the compiled contact direction aligns toward surface-inward;
- the authored rotation bias is applied once after automatic alignment;
- successive path samples preserve scale and use supplied surface normals;
- sampling distance uses the compiled contact distance, not the profile's
  maximum visual envelope;
- clicking without a nonzero stroke path creates no invisible zero-volume body
  or empty committed layer.

The current click-only behavior is intentionally a no-op. A one-click profile
stamp would be a separate explicit design decision if wanted later.

### Spline Line Uses The Same Saved Geometry

Saved Basic profiles also drive Spline Line bodies:

- the fixed cross-section is the same compiled polygon;
- the profile plane stays perpendicular to the path tangent;
- per-point surface normals establish the changing orientation frame;
- changing normals can roll/screw the profile around the path;
- rotation bias is applied after the automatic frame;
- a nonzero spline path is required before the body is commit-ready.

### Visual, Volume, Layer, And WIP Truth Agree

The same profile/path-frame authority now feeds:

- the visible CSG/preview presenter;
- the material-volume resolver;
- material-body state;
- committed layer input records;
- Forge V2 authoring/WIP persistence.

Persisted profile-path data includes:

- saved profile ID and display name;
- fixed anchor-relative polygon;
- path points and path surface normals;
- relative contact point;
- contact direction and distance;
- runtime schema;
- rotation bias;
- material and placement data.

The presenter and material-volume resolver share the same path surface-normal
interpolation and frame construction. They no longer independently invent the
profile orientation.

### UI Corrections Included In This Pass

- Saved Basic Shape size is displayed as fixed width by height.
- Primitive radius controls are disabled while a saved Basic Shape is active.
- Status and action-status surfaces use the fixed profile size rather than the
  dormant primitive brush radius.
- Switching back to a primitive restores radius authority.
- Invalid saved Basic records remain visible but cannot be selected as usable
  Shape authority.
- The earlier Fillet Size Apply path now commits the text actually typed into
  the SpinBox before reading and applying it.
