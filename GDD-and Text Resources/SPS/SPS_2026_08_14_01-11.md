## User Intent And Locked Direction

Forge V2 must retain solid-modeling behavior—Add, VOID, Replace, saved-profile
sweeps, Handles, materials, and later controllable seams—without making the
user fight an ever-growing CSG history tree.

The target model is:

```text
tool gesture
  -> immutable workpiece command
  -> one evolving closed/material-labelled solid revision
  -> derived authoring mesh + collision
  -> finalized lightweight runtime asset
```

Locked product ideas:

- A stroke is an operation, not permanent live geometry.
- The WIP keeps rich editable solid/material/Handle truth.
- Equipped gameplay and Skill Crafter use a lightweight compiled copy.
- Undo is convenience and may begin at five accepted actions, increasing only
  when measured safe; use snapshots/deltas, not reverse mouse replay.
- The legacy target plane is a first-contact/seed scaffold, not permanent
  workpiece matter. It should become non-targetable after a real seed exists.
- Final/equippable output must be one genuinely connected component. A future
  Island Inspector should focus/highlight/delete floating components and offer
  `Delete All Floating`, protecting the seed component (largest only as a
  fallback).
- Organic visual geometry remains required. The 4 mm field described below is
  strictly a locality carrier, not the final appearance.

## Architecture Decision So Far

Do not frame the decision as “CSG or no CSG.” Keep CSG/Boolean authoring
semantics, but stop treating an unbounded Godot SceneTree CSG operand tree as
the workpiece database.

The current decision ladder is:

1. Permanent Godot CSG history tree: rejected as the final live authority.
2. Bounded rolling CSG absorption: valid lifecycle bridge and correctness
   oracle, but rejected as the final mature-workpiece live compiler because it
   still reprocesses the whole growing mesh.
3. Spatially local labelled-solid/SDF/chunk backend: current experiment.
4. Native Manifold worker or exact/local hybrid remains available if field
   fidelity cannot preserve authored dimensions and sharp features.

## Current V2 Construction Truth That Motivated This Work

- Every accepted stroke remains a `ForgeV2MaterialBody` and committed layer.
- Same-material overlapping bodies render under one zone/root result, but the
  original operands remain children and are rebuilt when zone membership
  changes.
- The red seam is Boolean result geometry, not a separate saved connector body.
- Simple same-material node count is approximately linear in stroke count, but
  each connected release rebuilds the growing zone. Cumulative work therefore
  becomes at least quadratic; mixed clip operands can be worse.
- Material accounting already resolves bodies into one transient labelled cell
  map, but its 12.5–25 mm accounting grid is not a geometry authority.
- Reducing undo alone does not consolidate active geometry.

## Rolling CSG Proof And Measured Limit

The isolated rolling backend retained one accepted mesh plus a bounded pending
window. Window five meant peak six transient operands and zero steady operands.
Its transactional verifier and no-op refeed verifier passed. A deterministic
connected-raster stress was stopped intentionally after operation 5,000 because
the curve was already decisive.

At operation 5,000:

- compile p50: `760.802 ms`
- compile p95: `850.392 ms`
- compile p99: `911.475 ms`
- compile maximum: `1009.502 ms`
- headless frame-gap p95: `811.729 ms`
- elapsed: `1964.607 s`
- peak temporary operands: `6`
- steady operands: `0`

Stable fit from operation 500:

```text
compile_p95 ~= 25.72 + 0.16007 * operation_count milliseconds
R^2 ~= 0.99870
```

Per-edit cost remained approximately linear in accepted workpiece growth, so
cumulative session time was effectively quadratic (`R^2 ~= 0.999998`). A
10,001-operation continuation would mostly confirm durability and was projected
near 2h06m; it was not run.

A hardened 100-operation phase lane showed the deferred Godot CSG settle was
the dominant cost (~58.974 ms p95); node construction, bake reference retrieval,
and surface consolidation were comparatively small. This proves that moving
the same whole-workpiece Boolean behind bounded nodes does not solve locality.

## Tools-Only Chunked Locality Prototype

Added isolated experiment files:

- `tools/forge_v2_chunked_labelled_solid_backend.gd`
- `tools/benchmark_forge_v2_workpiece_compiler_chunked_field.gd`
- `tools/verify_forge_v2_chunked_labelled_solid_backend.gd`
- shared deterministic fixture: `tools/forge_v2_workpiece_stress_fixture.gd`
- shared analyzer: `tools/forge_v2_workpiece_benchmark_mesh_analyzer.gd`

Current backend contract:

- 4 mm cells in sparse 16x16x16 chunks.
- Per-chunk `PackedByteArray` material-label and protected-mask channels; no
  per-cell Dictionary authority.
- Supports only straight, constant-frame, saved-profile explicit-B/C,
  same-material `Add + Replace Existing` Volume Strokes.
- Requires overlap or face attachment.
- Applies changed cells and remeshes changed chunks plus six neighbors.
- Builds one combined boundary mesh only for checkpoints.
- Uses no CSG nodes and touches no player saves.
- VOID, second material, Handles, curved paths, Detailing, persistence, undo,
  background workers, collision publication, and organic meshing are explicitly
  unsupported.

## Known Blockers And Audit Findings

1. **Runner parse blocker:**
   `benchmark_forge_v2_workpiece_compiler_chunked_field.gd::_script_constant()`
   calls non-static `get_script_constant_map()` directly on the script resource.
   Replace it with direct backend constants or a valid instance query. Then run
   the benchmark script itself for one operation. The editor filesystem scan did
   not catch this tool-only execution error.
2. **Axis-aligned fixture blind spot:** `_rasterize_body()` scans every cell in
   the world-axis AABB. A long slender diagonal stroke can examine millions of
   empty cells even though accepted occupancy is small. Add
   `examined_cell_count`, an oriented/segment-local scan, and a diagonal lane.
3. **Attachment is existential, not complete:** one touching candidate cell
   accepts the entire candidate set. Prove every introduced candidate component
   joins the accepted workpiece, or reject the operation.
4. The current block-face mesher is intentionally pixel geometry, not an
   organic fidelity solution. Passing locality only authorizes the next field /
   adaptive/SDF meshing experiment.
5. Combined checkpoint concatenation/topology analysis is whole-workpiece work;
   keep it separate from ordinary edit timing.
